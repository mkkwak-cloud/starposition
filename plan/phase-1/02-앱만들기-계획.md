# 02 앱 만들기 계획 (사용자 "진행" 대기)

## 목표
폰으로 웹주소를 열고 → 카메라로 하늘을 비추면 → 그 방향에 보이는 별자리 선·이름·정보가 화면 위에 겹쳐 보인다.

## 방식
- 설치 없는 웹페이지 하나(out/index.html). 서버 필요 없음. 아이폰·안드로이드 모두 브라우저로 열림.
- 인터넷 주소는 https 여야 카메라·방향센서가 켜지므로, 완성 후 GitHub Pages(무료 정적 주소)에 올림.

## 필요한 정보와 받아올 곳
| 정보 | 출처 |
|---|---|
| 내 위치(위도·경도) | 폰 GPS (브라우저 위치 허용) |
| 지금 시각 | 폰 시계 |
| 폰이 향한 방향·기울기 | 폰 방향센서 (아이폰은 "센서 허용" 버튼 필요) |
| 별 위치·밝기·이름 | 공개 별 목록(밝은 별 약 5천 개) → data/ 에 받아 둠 |
| 별자리 선·한글 이름 | 공개 별자리 자료 → data/ |
| 해·달·행성 위치 | 계산 도구(astronomy-engine, 인터넷에서 받아 붙임) |
| 별자리 설명(신화·계절) | 직접 정리한 짧은 글, 88개 중 대표 별자리부터 |

## 단계
1. **하늘 지도 먼저(카메라 없이)** — 위치·시각으로 별을 그림. PC에서 바로 확인 가능. 별 위치 계산이 맞는지 검증.
2. **카메라 + 방향센서 붙이기** — 카메라 화면 위에 별·선·이름 겹침. 폰을 움직이면 따라 움직임.
3. **정보 표시** — 별자리를 누르면 이름·밝은 별·볼 수 있는 계절·지금 높이/방향·간단 설명. 해·달·행성 표시.
4. **인터넷에 올리기** — GitHub Pages, 폰에서 실제 확인.

## 알아둘 한계
- 방향센서는 폰마다 오차가 있어 (어림값 5~10도) 별이 살짝 어긋날 수 있음 → "보정" 버튼(밝은 별 하나에 맞추기) 제공 예정.
- 도시 불빛·구름은 카메라에 그대로 보임. 별 위치는 계산이라 상관없음.
- 실제 폰 센서 시험은 PC에서 불가 → 4단계에서 사용자가 폰으로 확인.

## 취향 질문 (A/B)
- 화면 분위기: A) 어두운 밤하늘 톤(눈 편함) / B) 기존 Information 앱처럼 흰 배경 + 파랑·청록 톤
